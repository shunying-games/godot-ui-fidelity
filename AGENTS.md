# Maintaining this skill

This repository is the reusable Godot UI skill. Keep project-specific asset paths, gameplay decisions, local helper commands, credentials, and raw QA artifacts in the consuming project's own documentation or ignored local storage. Read `SKILL.md` when changing the skill's behavior.

Before a commit, run `python3 -B -m unittest discover -s scripts -p 'test_*.py'`, stage only intended files, run `python3 scripts/check_publication.py --staged`, and review the staged diff. Use `python3 scripts/install_hooks.py` to enable local pre-commit and pre-push checks. Check outgoing history before publication and use a GitHub noreply author email. Diagnostics and reports must not print sensitive matches.

Keep English and Chinese READMEs consistent when installation or maintenance behavior changes. Explain what was verified; these deterministic checks do not demonstrate all-game visual quality or guarantee the absence of private facts. Commit/push only within the user's authorized scope, to the explicitly selected branch; preserve unrelated changes and remote history.

The Moonwell Bastion showcase presents GPT Image design art followed by the skill-assisted native Godot result. Keep one runnable implementation and distinguish generated concept art from actual runtime captures. Preserve the retained implementation source hashes; update them explicitly when changing its code. Do not add rankings or claims about an unshown control implementation.

Keep generated logs, raw captures and exports outside Git. Current documentation figures are `docs/battle/reference.webp` and `docs/battle/with-skill.webp`, each at most 220,000 bytes. Historical figure paths/hashes stay in the publication guard solely so reachable Git history can still be checked. Original generated battle art and sliced runtime art may be included only at the exact `demos/battle-comparison/source-art/` and `shared/assets/` file paths with reviewed SHA-256 hashes and individual size caps in `scripts/check_publication.py`. Preserve source pixels when stripping metadata. PNGs must pass signature, chunk-order and CRC checks without textual, provenance or private metadata; WebPs must pass the static metadata-free container check. The sole approved font is the exact official Google Fonts Cinzel binary, distributed with its OFL license and recorded download URL. Check its TrueType structure and pinned hash; do not scan font bytes as text.

Review image pixels and strip metadata before updating any allowlist. Retain approved older hashes needed for full-history verification. A new path, changed binary or larger cap requires a concrete review; directory-wide exclusions and command-line bypasses are prohibited. These allowances cover the standalone original demos and their reviewed documentation figures, not consuming-project art or raw QA captures.
